# 06 混合异构 — 四层融合并行 ANN 🆕

## 概述

期末全新开发，融合 MPI + OpenMP + SIMD(AVX2) + CUDA 四层并行架构，实现极致性能。

## 四层异构流水线

```
┌─────────────────────────────────────────────────────┐
│  Layer 1: MPI 粗粒度数据并行                          │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐           │
│  │  Node 0  │  │  Node 1  │  │  Node N  │           │
│  └────┬─────┘  └────┬─────┘  └────┬─────┘           │
│       │             │             │                  │
│  ┌────▼─────┐  ┌────▼─────┐  ┌────▼─────┐           │
│  │ Layer 2: OpenMP 中粒度线程并行                    │
│  │ T0 T1..Tn│  │ T0 T1..Tn│  │ T0 T1..Tn│           │
│  └────┬─────┘  └────┬─────┘  └────┬─────┘           │
│       │             │             │                  │
│  ┌────▼─────────────▼─────────────▼─────┐           │
│  │ Layer 3: SIMD AVX2 细粒度向量化       │           │
│  │ 8-way FMA per instruction            │           │
│  └────────────────┬────────────────────┘           │
│                   │                                 │
│  ┌────────────────▼────────────────────┐           │
│  │ Layer 4: CUDA GPU 批量GEMM加速       │           │
│  │ Tiled GEMM + Shared Memory + FP16   │           │
│  └─────────────────────────────────────┘           │
└─────────────────────────────────────────────────────┘
```

## 编译

```bash
mkdir build && cd build && cmake .. && make
```

## 运行

```bash
mpirun -np 4 ./hybrid_all --data <dir> --threads 8
```
